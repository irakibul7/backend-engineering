# ADR-0003: Original content and assets

- Status: Accepted
- Date: 2026-08-30

## Context

The requested experience references a public website and repository. No root license file was visible during source review. The project is intended for Rakibul's portfolio and must demonstrate his authorship without creating copyright or attribution confusion.

## Decision

Treat the source as visual and interaction evidence only. Create original code, prose, examples, diagrams, icons/asset selection, metadata, and Rakibul branding. Use generic technical topic names only where needed to describe the curriculum. Cite primary technical sources.

Exact source reuse is allowed only after written permission or a compatible license is documented in this repository.

## Consequences

- Content creation is a major, deliberately iterative workstream.
- Visual fidelity can remain high while authorship and assets differ.
- Editorial review includes provenance and similarity checks.
- The source author is not presented as this project's author.
